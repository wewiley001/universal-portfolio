The Wabbajawn

Studio Independent (TGW Mods)
Release 2026
Platform(s) PC / XSX|S (WIP)
Engine Creation Kit
Role Mod Author
Work Duration

Info

The mod introduces a new weapon that, when fired at an NPC, turns them into randomized hostile creatures for 30 seconds. The weapon (for now) uses a vanilla gun asset in the base game as the basis for the Wabbajawn weapon. The effect is managed by a script written in Papyrus — the proprietary scripting language used in Bethesda/Creation Engine games.

Background

The weapon was inspired by another iconic weapon, the Wabbajack, from another Bethesda game series (The Elder Scrolls), which had a similar effect.

There are eventual plans to release this mod on Bethesda's mod management site for Xbox release.
